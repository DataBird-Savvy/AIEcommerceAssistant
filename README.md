# 🛒 AI-Powered E-Commerce Assistant  

An **AI-driven e-commerce platform** that personalizes shopping experiences with **real-time product recommendations** and a **dynamic price negotiation engine**.  

Built to simulate **real-world online shopping** where customers can explore products, get personalized suggestions, and negotiate discounts — just like in real life.  

---

## ✨ Features  
- **🔎 Personalized Recommendations**  
  - Suggests products based on customer profile, purchase history, and preferences.  
- **🤝 Negotiation Engine**  
  - Machine Learning–powered discount prediction.  
  - LLM-based intent classification for smart negotiation handling.  
- **📊 Customer Profiling**  
  - Considers subscription status, ratings, and purchase behavior.  
- **🌐 Real-Time Product Info**  
  - Scrapes live product details for accurate display.  
- **🖥 Interactive UI**  
  - Streamlit-based interface for seamless shopping & negotiation.  

---

## 🛠 Tech Stack  
- **Backend:** Python, Streamlit, (FastAPI planned for scaling)  
- **AI/ML:**  
  - Scikit-learn → Discount prediction  
  - LangChain + OpenAI GPT → Intent classification  
- **Data:** Pandas (profiling), FAISS (recommendation retrieval)  
- **Frontend:** Streamlit UI
